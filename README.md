# Skillable at GA

General Assembly's guides for delivering hands-on labs on Skillable: onboarding, instructor guides, authoring, CSM reporting, the McKinsey MTA launch checklist and learner materials.

The whole site is one self-contained file, `index.html`. Fonts, logos and images are embedded, so it also works offline when opened straight from a downloads folder.

## View it

- **Online:** this repository is published with GitHub Pages (Settings → Pages → Deploy from a branch → `main` / root).
- **Offline:** download `index.html` and open it in any modern browser.

## Update it

Each guide is plain Markdown inside `index.html`. Search the file for `DOC 02` (or any guide number), edit the text in that block, and commit. GitHub Pages republishes automatically.

Full instructions, including the formatting conventions and how to add a new guide, are on the site's **Updating this site** page.
