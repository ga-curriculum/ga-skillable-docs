Program launch checklist

Every task, owner and lead time, from first decisions to the wrap-up.

Audience
The whole delivery team
Time
8 min read

"Day 1" is the first day of delivery. "Day 1 − 21" means 21 calendar days before. These are recommended lead times. Earlier is always fine.

Your ticks are remembered in your browser, so you can come back to this page as the program moves along.

Before launch

30+ days before Day 1: decisions

Task Owner Done
Decide lab visibility: current lab only, all labs, or current plus past CSM with the client
Decide whether any labs are scored, and the passing score for each LED with the client
Decide whether labs are ephemeral or saveable CSM, LED, with Lab admin
Decide how learners enroll: roster CSV or training key CSM, with Lab admin
Decide post-class lab access (extra hours after the program ends, if any) CSM, with Lab admin
Request any non-default lab settings (lab duration, idle timeout, closed-window timeout) Delivery team → Lab admin
Confirm which tools and packages learners need on the VM SME → Lab admin

Anything not requested by this point runs on Skillable’s defaults: 15-minute idle timeout, 60-minute closed-window timeout.

Day 1 − 21: content and people

Task Owner Done
Roster CSV programs: request the learner roster from the client (first name, last name, email for every learner) CSM
Final lab instructions for the opening sessions delivered in Markdown, with activities specified LED / SME → Lab admin
TMS accounts and roles set up for instructors (Instructor) and CSMs (Operations Manager) Lab admin
Instructors and CSMs sign in to TMS and confirm they can see the class Instructors, CSM

Day 1 − 14: build and review

Task Owner Done
Opening labs loaded, configured as decided, and published Lab admin
LEDs and SMEs review the labs end to end in a real lab launch LED / SME
Fixes from the review sent to Lab admin LED / SME
Roster CSV programs: roster filled in using the GA template and checked CSM

Day 1 − 10: learners get access

Task Owner Done
Roster CSV programs: roster imported and learners enrolled in the class CSM
Training key programs: class training key sent to the client with sign-up instructions CSM
Welcome email and learner handout sent to every learner CSM
Each instructor launches the lab, runs the full setup, and practices the exit routine (including Save and Close and relaunch, if the lab saves) Instructors

Day 1 − 5: close the gaps

Task Owner Done
Follow up with every learner who hasn’t confirmed sign-in and the connection test CSM
Raise corporate network or VPN failures with the client’s IT contact CSM
Late roster additions enrolled; for training key programs, roster checked against the client’s list CSM
Day-one slides include: the GitHub push routine, how to exit the lab (Save and Close, End or Cancel, as the program specifies), and how to get help Instructors

Day 1 − 2: final checks

Task Owner Done
Final instructor dry run on the published lab Instructors
Everyone knows the support routing, including Skillable support for after-hours or other-time-zone issues All
Instructors have Monitor Labs bookmarked from the Class page Instructors

Delivery

Day 1

Task Owner Done
Learners launch 10 minutes before start Instructors
Walk through the lab window, the push routine and the exit routine Instructors
Monitor Labs open for the whole session Instructors
End of day: push, check GitHub, then exit as the program specifies Instructors

For each later lab

Task Owner Done
Lab instructions delivered to the lab admin at least 14 days before the session LED / SME → Lab admin
Lab loaded, published and reviewed at least 7 days before the session Lab admin, LED / SME
Instructor test launch 2 days before Instructors
Reminder to learners about which lab to launch, 1 day before CSM
On the day: start-up routine on screen, and an end-of-session push reminder 15 minutes before close Instructors

Every session and the last one

Task Owner Done
End-of-session push reminder Instructors
Final session: confirm every learner’s repository is up to date on GitHub Instructors

After the program

Wrap-up

Task Owner Done
Post-class lab access applied, if agreed Lab admin
Final completion and progress report pulled from TMS CSM
Lessons learned shared with Lab admin for the next cohort All
