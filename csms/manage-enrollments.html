Enroll and manage learners in TMS

What to do, and what to watch out for, when you enroll a class, add or remove a learner, move learners or fix an account.

Audience
CSMs
Time
8 min read

Most of this happens from the Admin menu at the top of TMS. This page covers what GA needs you to do and watch out for. Each section links to Skillable’s step-by-step guide for the clicks. If a menu item is missing for you, your role may not include it. Reach out to the lab admin.

Read this first

Enrolled is what Skillable bills for. Skillable charges GA for every learner marked Enrolled, and once the class starts that status can’t be changed. Get the roster right, and remove anyone who isn’t coming, before the start date.

Enrollment statuses

An enrollment is a learner’s registration for one class. The statuses you’ll use:

Status What it means
Enrolled Attending. Only Enrolled (or Audit) learners can launch labs once class starts. Billed, and locked once class starts
Requested Registered, not yet confirmed. Can still be changed after class starts
Cancelled No longer taking the class
Wait-Listed Waiting for a seat in a full class

Skillable recommends adding learners as Requested and marking them Enrolled on day one. Confirm with the lab admin which approach your program uses. You change statuses on the class Roster: pick the new status for each learner, then select Save Changes.

Import the roster and enroll the class

For programs using a roster CSV.

  1. Import the accounts. Use Admin, then Users, then Import Users. Leave the role as Basic User, and tick Force Password Change so learners set their own password. TMS checks every row and lists any errors before importing.
  2. Enroll them in the class. Open the class Roster, select Add Students, and add everyone. Set the status your program uses, then save.
  3. Send the welcome email.

And: Enrolling multiple students

Add a late learner

  1. Check they don’t already have an account (find an existing account). Never create a second one.
  2. Create the account with Admin, then Users, then Create User.
  3. Add them to the class Roster with the right status, and save.
  4. Send them the welcome email.

Step by step in Skillable’s docs: Creating a student user account

Remove a learner

  • Before the class starts: set their status to Cancelled on the class Roster and save.
  • After the class starts: if they’re Enrolled, TMS won’t let you change it. Reach out to the lab admin with the learner’s name and the class.

Move learners to another class

For example, when a class is rescheduled. On the new class Roster, use Add Students from Event and pick the original class. Everyone who was Enrolled there is copied across. Learners with other statuses aren’t.

Then cancel them in the original class before it starts, so they aren’t billed twice.

Fix account problems

Find an existing account

Use Admin, then Users, then Find Users. Add the Disabled filter set to Is Or Is Not Disabled, so closed accounts show up too, and search by email. If TMS says an email is already in use, this is how you find the account. Use it rather than creating another.

Step by step in Skillable’s docs: Managing an email address that is already in use

A learner’s email changed

Learners can’t change the email on their own account. Send the lab admin the learner’s name, their old email and their new one. Don’t create a new account for the new email.

A learner has two accounts

Merge them, so their work and enrollments are in one place. Decide which account to keep first, because its username and password are the ones that survive. The duplicate is deleted and this can’t be undone. If you don’t see Merge Users in the Admin menu, reach out to the lab admin.

A learner forgot their password

Learners reset it themselves at . They’ll get a reset link by email. If they don’t know which email is on their account, look it up.

Check whether a learner launched a lab

Use Admin, then Labs, then Find Lab Instances, and filter by learner, class or lab. If a lab isn’t listed, it hasn’t been launched. More on what you can report: Reporting, grading and client updates.
