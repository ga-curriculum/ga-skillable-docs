How learners get enrolled

The two ways to get learners into a class, when to use each, and how to prepare for them.

Audience
CSMs
Time
5 min read

Two options

There are two ways to get learners into a TMS class. Decide which one a program uses with the lab admin, at the start of planning.

Roster CSV Training key (self-enrollment)
How it works You collect names and emails from the client and upload them. TMS creates the accounts and you enroll the class GA gives the client a class code. Each learner registers themselves on the TMS sign-in page and is enrolled
Best for Most programs Very large clients, where collecting a roster isn’t practical
Work up front More: collecting and checking the roster Less: send one code
Follow-up Little. Everyone is confirmed before day one More. Check that everyone registered, used the right code and didn’t create a second account
Risk Low Typos in the code, in names or in emails, and duplicate accounts

If you use a roster CSV

What to collect from the client

For every learner: first name, last name, and the email address they’ll actually use to sign in (usually their work email). Ask for it at least 21 days before day one. The launch checklist has the full timeline.

Use the template

The roster has a fixed format. Ask the lab admin for the template and fill it in without adding, renaming or reordering columns. TMS rejects rows it can’t read.

Check it before you upload

Then import the roster and enroll the class.

If you use a training key

What you do

  • Get the class training key from the lab admin, once the class is set up in TMS.
  • Send learners the key and the sign-in page, . On the sign-in page they choose to register with a training key, then enter their name and email. Adapt the welcome email by replacing the login details with these instructions.
  • Make sure it’s the class training key, not a voucher code. They look similar.
