Looking for a word? Type part of it here.

TermMeaning
ABAActivity-Based Assessment: scoring built from activities.
ActivityA question or automated check inside a lab.
Automated activityA script that checks the learner’s environment.
ClassA scheduled, instructor-led run of a course with start and end dates.
CourseA set of labs (and other content) in TMS.
Cloud credential poolA set of cloud sign-in details Skillable hands out to learners, one set each, shown in the lab instructions.
Cloud subscriptionA cloud account (such as Azure or AWS) a lab launches against, so learners can use real cloud services.
Course AssignmentSelf-paced access to a course, with no class dates. GA’s instructor-led programs use classes instead.
EnrollmentA learner’s registration in a class. Only Enrolled status gives access.
Environment variableA named setting inside the lab machine, such as an API key, that tools can read. One set by hand lasts only as long as that terminal session or machine. Some are injected automatically at launch.
EphemeralDiscarded when the lab ends; next launch starts clean.
IDLxSkillable’s version of Markdown for lab instructions. Mostly standard Markdown, plus Skillable-only syntax.
Image / base imageThe saved VM that every launch is copied from.
Lab InstanceOne launch of a lab by one person. Each launch is a new instance.
Lab ProfileA single lab in Studio: its VMs, settings and instructions.
Lab Report ViewerTMS role for reporting on lab activity and scores.
Lab SeriesA group of lab profiles. A profile must be in a series to be published.
Monitor LabsInstructor view of all running labs in a class.
Operations ManagerTMS role for CSMs: enroll learners and connect them to classes.
Replacement token@lab.Something placeholder in lab instructions, filled in at launch.
Tech requirementsThe SME’s document listing everything a lab environment needs: tools, packages, cloud services, access, websites and credentials.
Roster CSVGA’s fixed-format file of learner names and emails, uploaded to TMS to create learner accounts. The other way GA can enroll learners.
Saved labA paused lab instance kept until its save expiry date.
Skillable StudioWhere labs are built: VM images, settings, instructions, activities. Used by the lab admin, plus up to three people building a course on shared licenses.
Skillable TMSTraining Management System. Users, classes, enrollments, monitoring, reports.
Take ControlInstructor works directly inside a learner’s lab.
Training keyA code learners enter on the TMS sign-in page to create their own account and enroll in a class. One of the two ways GA can enroll learners.
