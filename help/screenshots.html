The site shows a dashed Screenshot to add box wherever a screenshot is missing. Take the screenshots below, save each one with exactly the file name shown, and put it in the assets/screens/ folder. Refresh the page and the screenshot replaces the box. Nothing else to edit.

Before you start

  • Use test accounts only. A test learner and a test instructor, enrolled in a test class with two or three labs. Never capture real learners’ names or emails. If you can’t avoid them, blur them.
  • Same setup for every shot. Chrome, browser zoom at 100%, window about 1400 pixels wide, light mode, and no browser extensions showing.
  • Capture the web page only, without tabs, bookmarks or the address bar (unless a step says otherwise).
  • Save as PNG, named exactly as shown (lowercase, hyphens). Keep each file under about 1.5 MB.
  • How to capture: on Mac, Shift+Cmd+4. On Windows, Win+Shift+S.
  • Leave them plain. Don’t add arrows or boxes. If you want arrows or callouts later, they can be added on top of the plain screenshot.
  • Tick each one off as you go. Your ticks are saved in this browser.
Fastest order

Many of the must-haves come from one session. Sign in as the test learner and capture the sign-in page, password prompt, dashboard, Classes tab and Activities list, then launch a lab and capture the lab window, Exit menu and Help panel. Then switch to the test instructor for My Calendar, the class page, Monitor Labs and Take Control. Finally, use a CSM account for the Admin menu, Import Users and the class Roster.
