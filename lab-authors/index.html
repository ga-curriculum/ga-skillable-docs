LED onboarding

Keep writing lab instructions the way you do today. This is what to add so they work in Skillable.

Audience
Learning experience designers
Time
About 30 minutes

Your first 30 minutes

  1. Sign in to TMS so you can review labs in a real launch. 4 min
  2. Read How a lab gets built: who does what, and the lead times. 5 min
  3. Learn the five essentials every GA lab needs in its Markdown. 5 min
  4. Read the GA conventions for steps, callouts and code. 10 min
  5. Launch a published lab and see how the Markdown renders. See Test a lab. 10 min

Five things to know

1

You write Markdown, outside Skillable

Use your own lesson and lab templates. They’re loaded into Studio for you. If you need to build hands-on, set up a Studio working session.

2

Skillable’s Markdown has its own rules

Page breaks, check boxes, callouts and @lab tokens are Skillable-only. Mermaid diagrams and HTML details tags don’t render.

3

Previews lie

GitHub and VS Code can’t show Skillable syntax. The only true preview is a real lab launch.

4

You describe checks, the lab admin builds them

Write what each question or automated check should test, its points and its feedback.

5

Changes need notice

Instruction fixes need 24 hours. New tools or labs need at least 3 days.

The machine itself (tools, packages, cloud services, keys) is the SME’s side. See SME onboarding.
